# 拇指直连版：H 直接连接远节固定座

本版删除独立 H–R4 输出杆及独立 R4 销，H 与远节固定座共用转轴。指节长度为近节 30 mm、远节 40 mm；连接点在远节中点，距 IP 20 mm。保留侧装舵机和掌侧安装铰链。

## 打开哪个模型

- `thumb_straight.glb`：同一初始装配的浏览预览。
- `thumb_straight.step`：起始装配，实际为 MCP 2° / IP 3° 轻微预弯，并非完全伸直。
- `thumb_half_curl.step`：电机行程一半的装配。
- `thumb_full_curl.step`：末端装配，MCP 45.000863° / IP 59.997570°。
- 文件名含 `_with_reference`：额外包含两节半透明人体参考形状，不能作为加工件。
- `parts/`：25 个单独零件的 STEP。
- `thumb_direct.gif`：直连模块的闭环运动；`motion.csv`：1001 个位置的电机角度、关节角与指尖坐标。后续 Onshape 镜像总装使用了这套连杆几何。
- `link_dimensions.csv`：本版孔中心距；不要再用上一版杆长。

STEP 为实体装配快照，保留零件名称、颜色，不含原生参数历史与运动配合。三份装配是同一机构的不同姿态。

## 这次优化与正向运动学

从旧版侧置连杆的初始几何出发，重新综合 AB、BC、CDG、EF、FGH 与 ADE 支架尺寸，允许改变电机零位安装角。删除 L_tip_rod 变量；不是将旧杆长度设为零。固定 AD=21.112 mm、AD 倾角 37.054°、MCP=(0,-7) mm。

求解使用 12 次确定性多起点最小二乘，随机种子 20261018。优化目标为逼近从 2°/3° 到 45°/60° 的参考轨迹并保持有效圆交点、单调关节运动；参考插值只是轨迹综合目标。输出的真实角度来自 H 位置的两节闭环反解，不强制线性协同。长度包络 8–85 mm 为本次综合的软惩罚范围，不是原四指配置的硬边界；EF/DG 在数值结果中略高于 85 mm。并未证明全局最优或做体积最小化。

电机行程约 60.39210°。零位时 AB 相对未倾斜 AD 的数学方向角 115.08972°；电机正行程使这个角减小。CAD 已包含该安装相位，不能直接套用旧版舵盘零位。

以 MCP 为原点，H=(x,y)，a=30，b=20：

`IP = acos((x*x+y*y-a*a-b*b)/(2*a*b))`

`MCP = -atan2(y,x) - atan2(b*sin(IP),a+b*cos(IP))`

这是 y 轴向上、屈曲向下的连续解支。先将模型中的 H_y 加 7 转到 MCP 原点。指尖再由 30 mm 近节和 40 mm 远节计算。必须知道根部位置、连接点偏置并校准电机零位。实际穿戴的固定座滑移、关节轴偏移会带来误差。

起点有意保留 2°/3° 预弯，避免完全伸直时的两节共线死点；目前没有求解或验证越过该起点的伸展运动。完整三维手掌坐标还需要掌侧铰链角度，或将该铰链固定在已知角度。

## 已完成的检查与边界

- 1001 个位置真实闭环解，MCP/IP 均单调；位置闭合误差低于 2e-14 mm，刚体孔距误差低于 1e-12 mm（数值计算误差，不代表加工精度）。
- 两个驱动闭环的圆交点未发生切换或相切；两节拇指选定向下屈曲解支。
- 13 个姿态、517 次包围盒筛选后的实体相交检查，无大于 1e-4 mm³ 的硬件重叠。
- 三份装配 STEP 导回均为25个有效实体。
- 干涉检查不包含真实人体软组织、紧固件头部/螺纹、变形、间隙公差及连续扫掠；未进行舵机扭矩、舒适性或加工可行性认证。

## 重建

Python 3.12，安装 `cadquery==2.6.1 numpy scipy matplotlib pillow` 后，在本文件夹运行：

```
python optimize_direct.py
```

只重新搜索并输出 search_result.json 与运动学初检；不会自动覆盖 parameters.json 和已交付模型。如需用新搜索结果重新出图，先将 x 和 lengths 更新到 parameters.json，再更新电机角度采样表。

重建已交付的尺寸：

```
python report_direct.py
python build_thumb.py
python check_interferences.py
```

本包 seed_parameters.json 保存旧版作为搜索起点；交付模型始终读取 parameters.json 的直连参数。模型参考四指仓库提交 4d44b5aa750dcf5d5705079bb691e2836ea306ec 的孔径、板厚和电机外形，不是直接修改其 STL。
